### Text To Speech

A lightweight web app that converts text into speech using the **Web Speech API** (`SpeechSynthesisUtterance`). It needs no libraries, no backend and no API keys.

**Features**
- Type or paste any text
- Click **Text To Speak** to hear it read aloud
- Speech rate and pitch can be changed in the script
- Runs fully in the browser

**How to run**

```bash
git clone https://github.com/Nandhu0107/MiniProjects.git
cd MiniProjects/TextToSpeech
# open index.html in Chrome, Edge or Safari
```

**Files**

| File | Purpose |
